# ai-gym-planner

AI Gym Planner is a smart mobile fitness application developed by the team FitTech Innovators. The
project was created to provide users with a personalized and simple fitness experience using modern
Android technologies and AI integration.

Project Objective
 ->The main goal of the project is to help users track workouts, monitor activities automatically, and receive
AI-powered fitness recommendations.

Technologies Used
 ->The application was developed using Kotlin and Jetpack Compose. Firebase Authentication and Cloud
Firestore were used for cloud services and synchronization. The system also integrates Gemini AI,
Google Activity Recognition API, and Room Database.

Main Features
 ->The app allows users to log in using Google or email authentication, track workouts, view activity
history, and receive AI-generated suggestions. Automatic activity detection helps users monitor walking
and running without manual input.

System Architecture
 ->The project follows MVVM architecture to separate UI, business logic, and data layers. The application
uses an offline-first system where data is stored locally in Room database and synchronized with
Firestore when internet access becomes available.

Challenges
 ->During development, the team faced issues related to Google Sign-In configuration, Gradle dependency
conflicts, Android 14 restrictions, and UI scaling on small devices. These challenges were solved
through testing and optimization.

Future Improvements
 ->Future plans include adding advanced AI workout plans, analytics charts, wearable device integration,
and social features to improve user engagement and functionality.

Conclusion
 ->AI Gym Planner is a fully functional mobile fitness application built with modern technologies. The
project demonstrates practical implementation of AI, cloud synchronization, and offline support in
Android development.
